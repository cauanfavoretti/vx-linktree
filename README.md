# VX · Página de links

A aplicação React + Vite está em `outputs/vx-links/`.

## Desenvolvimento local

```sh
cd outputs/vx-links
npm ci
npm run dev
```

## Deploy na Vercel

Use a raiz do repositório como **Root Directory**. O `vercel.json` da raiz configura instalação e build em `outputs/vx-links` e publica `outputs/vx-links/dist`. Nenhuma variável de ambiente é necessária.

Os arquivos `outputs/vx-links/src/content.ts` e `outputs/vx-links/src/App.tsx` concentram conteúdo, destinos e interações.
